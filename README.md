# 🌸 Telegram-бот для записи в салон красоты

> Демо-проект. Клиент сам выбирает услугу и оставляет заявку прямо в Telegram, а администратор сразу получает уведомление. Без долгих переписок и звонков.

👉 **Попробовать бота:** [@trening_agent](https://t.me/trening_agent)

---

## Зачем салону такой бот

- **Клиенту удобно.** Прайс, адрес и запись находятся в одном месте, не нужно ни звонить, ни ждать ответа.
- **Администратор экономит время.** Бот сам отвечает на частые вопросы: сколько стоит, сколько длится, где находится салон.
- **Заявки не теряются.** Каждая запись сохраняется в базе, а администратор получает уведомление сразу.
- **Легко подстроить под любой салон.** Услуги, цены и адрес меняются в одном месте.

## Что умеет бот

**Для клиента**

- Меню с кнопками: **Прайс**, **Контакты**, **Оставить заявку**
- Прайс: список услуг → карточка услуги (цена, длительность, описание) → кнопка «Записаться»
- Запись по шагам: имя → телефон → услуга → время. Бот проверяет введённые данные
- Отмена заявки на любом шаге командой `/cancel`

**Для администратора**

- Уведомление о каждой новой заявке
- Команда `/requests`: последние 10 заявок
- Все заявки хранятся в базе данных

## Технологии

Python 3 · aiogram 3 (конечный автомат FSM) · SQLite · python-dotenv

## Запуск

1. Создайте виртуальное окружение и установите зависимости:

```bash
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # Linux / macOS
pip install -r requirements.txt
```

2. Скопируйте `.env.example` в `.env` и заполните:

```env
BOT_TOKEN=токен_от_BotFather
ADMIN_ID=ваш_telegram_id
```

3. Запустите бота:

```bash
python main.py
```

При первом запуске автоматически создаётся файл базы `salon.db`.

## Структура проекта

```text
main.py            # бот: меню, прайс, запись по шагам
db.py              # работа с базой SQLite
requirements.txt   # зависимости
.env.example       # пример настроек (без секретов)
```

## Настройка под другой салон

Услуги, цены и адрес лежат в начале `main.py` (словарь `SERVICES`, константы `ADDRESS` и `CURRENCY`). Чтобы добавить услугу, достаточно дописать один блок: кнопки и карточка появятся сами.
